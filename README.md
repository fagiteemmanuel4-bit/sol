# Strap — Frontend Rebuild

A from-scratch, responsive orange-and-warm-white frontend prototype for Strap, a retail and point-of-sale workspace.

## What's included
- Responsive dashboard and navigation
- Sales, inventory, orders, customers, online store, analytics, and settings screens
- Local demo data and frontend-only interactions
- CSV export and local-only demo forms

## Backend status
This phase intentionally has **no backend integration**. No authentication, database, payments, or real business records are connected. Form changes exist only in the current browser session and reset on refresh.

## Run locally
Open `index.html` in a browser, or deploy this static site with Vercel.
